# 4-Day Hypertrophy Program

Upper/Lower split, 4 days/week, built for a return-to-training beginner with
a wrist/shoulder history and joint hypermobility. Weekly order is
Upper A → Lower A → Upper B → Lower B, mapped onto real Mon/Tue/Thu/Fri
calendar dates below (not a recurring weekday template) so every session has
its own exact page with its own predicted weight.

**How the weight column works:** the weight next to each exercise is a
prediction, not a fixed prescription. The nearest upcoming (unlogged) date
for each exercise reflects the actual progression rule from
`hypertrophy-guidelines.md` — hit the top of the rep range on every set last
time it was trained → smallest available jump (2.5-5 lb barbell, next DB
increment); otherwise repeat the same weight. Dates further out just carry
that same number forward as a placeholder until they become the "nearest
upcoming" date themselves — `scripts/update-predictions.js` recomputes and
rewrites this file after each logged session, one exercise/date at a time,
so numbers get more accurate the closer a date gets rather than being
guessed a month in advance.
